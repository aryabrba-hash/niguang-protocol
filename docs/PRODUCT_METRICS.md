# 首发产品指标

首版只记录聚合事件，不记录姓名、通讯录、精确位置或每一道题的原始轨迹。

| 目标 | 事件/指标 | 用来回答的问题 |
| --- | --- | --- |
| 上手 | `tutorial_complete`、首局开始率 | 用户是否理解“先看规则”？ |
| 训练质量 | 首局完成率、正确率、平均反应时间 | 难度是否让玩家稳步进入状态？ |
| 留存 | 次日再次训练、每日协议完成天数 | 用户是否愿意自然回来？ |
| 心流 | 最高连击、断连后继续率 | 爽感是否鼓励继续，而非制造挫败？ |
| 性能 | 冷启动耗时、掉帧率、后台恢复成功率 | 真机体验是否稳定？ |
| 分享 | 结果页主动分享率、分享进入后的首局完成率 | 分享是否真实带来可玩的用户？ |

健康阈值建议先以内部测试建立基线，再做小流量 A/B；不使用无限红点、虚假倒计时、强制分享或连续弹窗提高数字。
